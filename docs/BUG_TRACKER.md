# BIGNET BUG & GAP TRACKER

## RULES

- Bug = implementasi salah.
- Gap = requirement belum lengkap.
- Bug/gap tidak otomatis mengubah locked requirement.
- Setiap bug harus memiliki evidence.
- Close hanya setelah retest.

## STATUS
OPEN / IN PROGRESS / BLOCKED / READY FOR RETEST / CLOSED
